Anthropic Claude, 연매출 $300억 런레이트 돌파
2026년 1분기 80배 성장, Claude Code는 출시 9개월 만에 연매출 $25억

Anthropic이 Claude의 연매출 런레이트가 $300억에 도달했다고 밝혔다. 2026년 1분기 성장률은 전년 동기 대비 80배로, 기업 역사상 가장 가파른 수익 곡선 중 하나로 평가된다.

특히 2025년 5월 공개 출시된 에이전틱 코딩 툴 Claude Code가 9개월 만에 연매출 $25억을 기록하며 성장을 주도하고 있다. AI 모델 단독 판매에서 에이전트 워크플로우 통합으로 수익 구조가 전환되고 있음을 보여주는 신호다.

LLM 자체보다 에이전트 워크플로우에서 실질 수익이 나오는 구조로의 전환을 확인하는 지표.
Google I/O: Gemini 3.5 Flash + 개인 AI 에이전트 Gemini Spark 발표
2시간 동안 100개 이상 발표, 플래그십 수준 성능을 4배 빠른 속도로

Google I/O에서 Gemini 3.5 Flash가 공개됐다. 이전 Gemini 대비 4배 빠른 속도로 코딩 및 에이전틱 벤치마크에서 Gemini 3.1 Pro를 넘어서는 성능을 보인다. 속도와 성능의 트레이드오프를 크게 줄인 것이 핵심이다.

또한 개인 AI 에이전트 Gemini Spark와 에이전틱 앱 개발을 위한 새 개발자 플랫폼도 함께 발표됐다. Google이 단순 AI 어시스턴트를 넘어 사용자의 일상 워크플로우에 깊이 통합되는 에이전트 생태계 구축에 본격적으로 나선 것으로 해석된다.

빠른 추론 모델이 에이전트 파이프라인의 핵심 인프라가 되고 있으며, 개인용 에이전트 시장 경쟁이 본격화되는 시점.
Anthropic MCP, 9,700만 설치 돌파 — 에이전트 표준 인프라로 자리잡아
2026년 3월 기준 모든 주요 AI 공급사가 MCP 호환 툴링 출시

Anthropic의 Model Context Protocol(MCP)이 2026년 3월 기준 9,700만 설치를 돌파했다. 실험적 표준에서 AI 에이전트 구축의 핵심 인프라로 전환됐음을 보여주는 수치다.

현재 OpenAI, Google, Meta 등 모든 주요 AI 공급사가 MCP 호환 툴링을 출시한 상태다. 특정 회사의 프로토콜이 업계 표준이 되는 것은 이례적인 일로, MCP는 에이전트가 외부 도구 및 데이터 소스와 상호작용하는 방식을 통일하는 역할을 하고 있다.

MCP를 이해하고 활용할 수 있는 능력이 에이전트 개발자의 핵심 역량이 됐음. 지금 배워야 할 가장 중요한 프로토콜.
OpenAI-Visa 파트너십: AI 에이전트가 결제를 직접 실행한다
사용자 허가 후 에이전트가 온라인 구매 자율 실행, 기업용 AI 결제도 탐색 중

OpenAI와 Visa가 파트너십을 체결해 AI 에이전트가 사용자 허가 하에 온라인 구매를 직접 실행할 수 있는 기능을 개발 중이다. 에이전트가 단순히 정보를 전달하는 것을 넘어 실제 트랜잭션을 수행하는 단계로 진화하는 신호다.

기업용 AI 결제 솔루션도 함께 탐색되고 있어, 에이전트가 구매 발주, 비용 처리 등 기업 재무 워크플로우에 통합되는 방향으로 발전할 전망이다.

에이전트의 "실세계 행동 실행" 능력이 결제 영역까지 확장되면서 에이전트 신뢰성과 권한 관리의 중요성이 높아지는 시점.
NVIDIA Agent Toolkit 오픈소스 공개 — 엔터프라이즈 에이전트 구축 플랫폼
AI-Q 하이브리드 아키텍처로 쿼리 비용 50% 절감, Adobe·Salesforce·SAP 등 통합

NVIDIA가 GTC에서 엔터프라이즈 AI 에이전트 구축을 위한 오픈소스 플랫폼 Agent Toolkit을 발표했다. 프론티어 모델을 오케스트레이션에, 오픈 Nemotron 모델을 리서치 작업에 활용하는 AI-Q 하이브리드 아키텍처가 핵심으로, 정확도는 높이면서 쿼리 비용을 50% 이상 절감한다고 밝혔다.

Adobe, Atlassian, Salesforce, SAP, ServiceNow, Siemens 등 주요 엔터프라이즈 소프트웨어사들이 통합을 발표했다. 기업 AI 에이전트 시장에서 NVIDIA의 소프트웨어 레이어 확장 전략의 일환이다.

하드웨어 회사 NVIDIA가 에이전트 소프트웨어 스택으로 영역을 확장하며, 엔터프라이즈 에이전트 인프라 경쟁의 새 플레이어로 등장.

오늘의 핵심 주제

Model Context Protocol(MCP) — 에이전트 시대의 USB 표준

배경: 왜 MCP가 필요했나

AI 에이전트가 외부 도구(파일 시스템, 데이터베이스, API, 브라우저 등)와 상호작용하려면 각 도구마다 별도의 통합 코드를 작성해야 했다. N개의 에이전트 프레임워크와 M개의 도구가 있으면 N×M개의 커스텀 연결이 필요한 구조였다. MCP는 이 문제를 "표준 플러그"로 해결한다.

핵심 구조: Host / Client / Server

MCP Host는 Claude Desktop, VS Code 같은 AI 애플리케이션이다. MCP Client는 호스트 내부에서 서버와 1:1 연결을 유지하는 프로토콜 클라이언트다. MCP Server는 특정 기능(파일 읽기, DB 쿼리, 웹 검색 등)을 표준 인터페이스로 노출하는 경량 프로그램이다.

통신은 JSON-RPC 2.0 기반으로, 서버는 세 가지 기본 기능을 제공한다: Tools(에이전트가 실행할 수 있는 함수), Resources(읽을 수 있는 데이터), Prompts(재사용 가능한 프롬프트 템플릿).

왜 9,700만 설치인가 — 네트워크 효과

MCP 서버를 한 번 만들면 MCP를 지원하는 모든 AI 클라이언트에서 바로 쓸 수 있다. Anthropic이 사양을 공개하고 오픈소스로 관리하면서 OpenAI, Google, Microsoft 등이 모두 호환 툴링을 출시했다. 이미 수천 개의 커뮤니티 MCP 서버가 존재하며(GitHub, Slack, PostgreSQL, Figma 등), 새로운 AI 앱을 만들 때 MCP 지원은 사실상 필수가 됐다.

실용적 의미 — 지금 당장 할 수 있는 것

Claude Desktop에서 MCP 서버를 설정하면 AI가 로컬 파일, 데이터베이스, 외부 API를 직접 읽고 실행할 수 있다. 개발자라면 @modelcontextprotocol/sdk로 커스텀 MCP 서버를 30분 안에 만들 수 있다. 기업 환경에서는 사내 시스템을 MCP 서버로 래핑해 AI 에이전트에게 안전하게 노출하는 아키텍처가 표준이 되고 있다.

오늘의 학습 포인트

1
Model Context Protocol(MCP)의 Host-Client-Server 구조를 이해하라. 에이전트가 외부 도구와 표준화된 방식으로 상호작용하는 핵심 프로토콜이다. 직접 MCP 서버를 하나 만들어보는 것이 가장 빠른 학습법.
2
에이전트의 "실행 능력"이 확장되고 있음을 인식하라. 결제(OpenAI-Visa), 코드 작성(Claude Code), 기업 시스템 연동(NVIDIA Toolkit) 등 에이전트가 단순 텍스트 생성을 넘어 실세계 액션을 수행하는 방향으로 발전 중. 권한 관리와 안전성이 핵심 이슈.
3
빠른 추론 모델(Flash 계열)의 에이전틱 파이프라인 활용법을 익혀라. Gemini 3.5 Flash처럼 속도와 비용을 최적화한 모델이 에이전트 파이프라인의 중간 계층을 담당하는 하이브리드 아키텍처가 표준이 되고 있다. 무조건 최대 모델보다 태스크별 모델 선택이 중요해지는 시대.
