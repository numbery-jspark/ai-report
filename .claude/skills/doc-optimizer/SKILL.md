## 개요

프로젝트의 마크다운 문서를 분석하여 중복을 제거하고 최적화합니다.

## 동작 흐름

### 1단계: 문서 분석
- 프로젝트 내 모든 .md 파일 검색
- 각 파일의 크기, 주제, 섹션 파악

### 2단계: 중복 감지
- 파일 간 내용 중복 검출
- 섹션 중복 찾기
- 정보 산재도 측정

### 3단계: 통합 계획
- 통합 가능한 파일 그룹화
- 최적 폴더 구조 설계
- 신규 파일 템플릿 제안

### 4단계: 자동 최적화
```powershell
# 통합 문서 생성
# 불필요한 파일 삭제
# Git 커밋 & 푸시
git add .
git commit -m "refactor: Optimize documentation"
git push
```

### 5단계: 결과 보고
- 최적화 전후 비교
  - 파일 수: X → Y
  - 총 줄 수: A줄 → B줄 (감소율 %)
- 정보 보존율: 100%

## 입력

- **repo_path**: 프로젝트 경로
  - 예: `C:\Users\Admin\Desktop\ai-report`
- **target_count** (선택): 목표 문서 수
  - 기본: 자동 최소화

## 출력

- 최적화 보고서 (파일 수, 크기 비교)
- 통합 구조 다이어그램
- 삭제된 파일 목록
- GitHub 커밋 해시

## 사용 예시

**입력:**
```
저장소 경로: C:\Users\Admin\Desktop\my-project
목표 파일 수: 3
```

**출력:**
```
✓ 분석 완료: 6개 파일 발견
✓ 중복 감지: 3개 섹션 중복
✓ 통합 계획: 6개 → 3개 파일
✓ 최적화 완료
  - README.md (핵심)
  - .docs/CONFIG.md (설정)
  - .docs/GUIDE.md (개발)
✓ 삭제: CLAUDE.md, SOUL.md, ISSUES.md
✓ 커밋: abc1234
```

## 기술 요구사항

- Git 설치 및 설정
- 저장소 쓰기 권한
- 마크다운 파일만 대상
